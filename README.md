## Установка и запуск

Требования
- Python 3.12 или выше
- uv

### Установка

Клонируйте репозиторий и перейдите в папку проекта: git clone <ссылка-на-репозиторий>
cd primitive_db

Установите зависимости: uv sync

### Запуск

Запустите приложение:uv run database

Проверка кода

Проверьте код с помощью Ruff: uv run ruff check .

## Управление таблицами
База данных позволяет создавать, просматривать и удалять таблицы. Метаданные таблиц сохраняются в JSON-файле 'db_meta.json'l.

### Описание команд
'create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ..' - cоздать таблицу
'list_tables' - показать список всех таблиц
'drop_table <имя_таблицы>' - yдалить таблицу
'exit' - выход из программы 
'help' - справочная информация 

### Пример использования
Запустите программу в терминале: uv run database

Создайте таблицу 'users':
Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

Посмотрите список таблиц:
Введите команду: list_tables
- users

Попробуйте создать таблицу с тем же именем:
Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.

Удалите таблицу:
Введите команду: drop_table users
Таблица "users" успешно удалена.

Для просмотра доступных команд введите 'help', а для выхода из программы - 'exit'.


## CRUD-операции
База данных поддерживает операции CRUD (Create, Read, Update, Delete), позволяющие добавлять, просматривать, изменять и удалять записи в таблицах.
Данные каждой таблицы хранятся в отдельном JSON-файле в директории data/.

### Описание команд
'insert into <имя_таблицы> values (<значение1>, <значение2>, ...)' - создать запись.
'select from <имя_таблицы> where <столбец> = <значение>' - прочитать записи по условию.
'select from <имя_таблицы>' - прочитать все записи.
'update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия>' - обновить запись.
'delete from <имя_таблицы> where <столбец> = <значение>' - удалить запись.
'info <имя_таблицы>' - вывести информацию о таблице.

### Пример использования
Создадим таблицу users с полями имени, возраста и статуса активности:

Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

Добавим запись: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

Прочитаем все записи: select from users
{'id': 1, 'name': 'Sergei', 'age': 28, 'is_active': true}

Найдём пользователя по возрасту: select from users where age = 28
{'id': 1, 'name': 'Sergei', 'age': 28, 'is_active': true}

Изменим возраст пользователя: update users set age = 29 where name = "Sergei"
Записи в таблице "users" обновлены.

Удалим запись по ID: delete from users where ID = 1
Записи из таблицы "users" удалены.

Посмотрим информацию о таблице: info users
Таблица: users
Столбцы: id:int, name:str, age:int, is_active:bool
Количество записей: 0

## Обработка ошибок

Декоратор handle_db_errors обрабатывает основные ошибки базы данных:
KeyError — обращение к отсутствующему ключу, таблице или столбцу;
ValueError — ошибка валидации данных;
FileNotFoundError — отсутствие файла.

Декоратор confirm_action(action_name) запрашивает подтверждение перед выполнением опасной операции. Он используется при удалении таблиц и записей.

## Кэширование запросов

Функция create_cacher() создаёт замыкание, хранящее результаты вычислений в словаре. Кэширование используется в операции select, чтобы повторно получать результат одинакового запроса без повторной фильтрации данных.
Ключ кэша учитывает данные таблицы и условие выборки, чтобы при изменении данных не использовать результат для прежнего состояния таблицы.
